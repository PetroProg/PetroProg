## Linux and Self-hosting

I use Linux every day, on a home server and for school work.

[![Linux](https://skillicons.dev/icons?i=linux,ubuntu,fedora,bash,docker,nginx,git&theme=dark)](https://skillicons.dev)

- **Server:** Ubuntu Server on modest hardware (Intel Celeron N3060), administered over SSH.
- **Workstation / practice:** Fedora Linux.
- **Containers:** every service runs in Docker Compose.
- **Network access:** private access and HTTPS through Tailscale; Nginx as a reverse proxy.
- **Self-hosted projects:** [Jellyfin-Spotify](https://github.com/PetroProg/Jellyfin-Spotify), [Recipe-App](https://github.com/PetroProg/Recipe-App), [AI-news](https://github.com/PetroProg/AI-news).

### Linux-Learning

[Linux-Learning](https://github.com/PetroProg/Linux-Learning) is a hands-on practice repository for Linux administration and automation on Fedora, made as preparation for the school Linux modules.

| Area | What I practiced |
|---|---|
| System and files | Filesystem navigation, permissions and ownership (`chmod`, `chown`), processes (`ps`, `grep`, `kill`), logs (`journalctl`, `tail`), disk usage (`df`, `du`) |
| Networking and security | Interfaces and routes (`ip a`, `ip r`), connectivity and DNS (`ping`), listening ports (`ss -tulpn`), firewall status (`firewalld`) |
| Bash automation | `sysreport.sh` (system health report to a log), `backup.sh` (incremental `rsync` backup) |
| systemd | User-level `backup.service` and `backup.timer` running the backup every hour |
| Shell | Custom aliases in `.bashrc` (for example `syslog`) |

Structure: `configs/`, `logs/`, `notes/` (command reference), `scripts/`.
